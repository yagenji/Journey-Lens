NEW表示日数をCMSで変えられるようにする更新（3ファイル）
=====================================================
リポジトリの同じ位置のファイルを、これで置き換えてコミットしてください。

  index.html            → リポジトリのルート（置き換え）
  build.py              → リポジトリのルート（置き換え）
  admin/config.yml      → admin/config.yml（置き換え）

置き換え後の使い方：
  CMSの「並び・設定 → 国の並び順」を開くと、「NEWを表示する日数」欄が増えています。
  ここに数字（例: 14）を入れて保存すると、公開日からその日数だけ NEW が出ます。
  空/未設定なら 30日（従来どおり）。
  ※ 保存すると自動ビルドが走り、サイトに反映されます。
